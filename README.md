# பைபிள் புத்தக ஆய்வு (Bible Books Research)

Tamil research notes on Bible books, chapter by chapter, based only on jw.org / wol.jw.org.

- Standards for research and UI: [STANDARDS.md](STANDARDS.md)
- Raw source notes: `research/<book>/`
- Site: static HTML — open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).

Done: கலாத்தியர் 1–6

To add another book at the same quality: see [playbook/README.md](playbook/README.md).
